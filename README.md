# BEADS Atelier & Réserve

ビーズの図案室と倉庫。ブラウザーで図案を作成し、手持ちのビーズを管理するアプリです。

## 使い方

[使い方マニュアル（PDF・全4ページ）](manual.pdf)

## できること

- 半目ずらし（ペヨーテ型）・格子（スクエア・織り型）の図案作成
- 自分で色を作り、パレットに追加（初期パレットは10色）
- 範囲の選択・コピー・貼り付け・移動・消去
- 図案とパレットのJSON保存・読み込み、印刷用PDFの書き出し
- カタログからの色の追加と、ビーズ倉庫の数量管理

図案とビーズ倉庫は、それぞれ独立したJSONファイルに保存します。

## カタログについて

図案づくりの参考として、MIYUKIデリカビーズのカタログを収録しています。表示色・質感は目安であり、実物とは異なります。本アプリは株式会社MIYUKIの公式アプリではありません。

情報の出典：[BEADS FACTORY デリカビーズ検索](https://www.beadsfactory.co.jp/lookfor/db.html)

カタログ情報・商品画像等の第三者由来の素材は、アプリ独自のコードとは区別して扱います。このリポジトリの公開によって、それらの自由な再利用・再配布を許諾するものではありません。
