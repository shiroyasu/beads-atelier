01 / PREPARE制作の準備をする

名前・マス目・色を決めて、図案づくりを始めましょう。

初めて開いたときは
10色のパレットと参考図案が表示されます。そのまま描いて試せます。白紙から始める場合は、図案下部の「新規作成」を押してください。

操作位置の模式図です。画面幅により配置が変わります。

  1. 図案の名前を入力する

    画面上部の図案名をクリックして、作品の名前を入力します。名前は図案ファイルや、書き出したPDFにも使われます。

  2. マス目の配置を選ぶ

    図案名の横にある「半目ずらし（ペヨーテ型）」または「格子（スクエア・織り型）」を選びます。切り替えると白紙になります。確認画面で、今の図案をファイルに保存してから切り替えることもできます。パレットと倉庫は引き継ぎます。

  3. 図案の大きさを決める

    図案下部で「幅（列）」「高さ（段）」を入力し、「サイズ変更」を押します。それぞれ2〜100を指定できます。小さくすると、範囲外のビーズが消えるので注意してください。

  4. 色を作ってパレットに追加する

    左側の「＋ 色を作る」を押します。名前（必須）・品番（任意）・表示色を設定し、「パレットに追加」を押してください。品番が分からなくても色を作れます。

  5. カタログの色を参考にする

    「＋ カタログから選ぶ」から、収録ビーズの色を追加できます。詳しくは「ビーズをカタログから選ぶ」へ。パレットには自由に作った色とカタログの色を一緒に登録できます（最大64色）。

  6. 保存した図案を開く

    画面上部の「開く」から図案のJSONファイルを選びます。図案とパレットが置き換わり、ビーズ倉庫は変更されません。

  7. 印刷用のPDFを書き出す

    「図案の書出し」を押すと、図案名・図案・使用ビーズ一覧をA4縦1枚のPDFにまとめます。図案は縦長になる向きに配置し、単色と色記号で表示します。細かな図案は印刷時に記号の読みやすさを確認してください。PDFは編集用の図案JSONとは別です。

02 / DRAW図案を描く

パレットで色を選び、図案上に置いていきます。

  1. 描くビーズを選ぶ

    左側のパレットで色をクリックします。色が多い場合は、パレットの一覧部分だけをスクロールできます。「並び順」で追加順・品番順・色系統順・加工方法順を選べます。「単色／質感見本」はパレットの見え方を切り替えます。

  2. 描く・消す・確認する

    ペンのボタンで描き、消しゴムのボタンで消します。ドラッグすると連続して操作できます。「確認」でビーズをタップすると、図案直下に品番・色名が表示されます。パソコンではマウスを重ねるだけでも確認できます。カタログのビーズには商品ページのリンクが表示されます。

  3. 見やすい向き・倍率にする

    左回転・右回転で表示を90度ずつ回転し、＋／−で拡大・縮小します。「色記号」「質感見本」も切り替えられます。長い図案は表示領域の中で縦・横にスクロールしてください。回転は見せ方の変更で、図案のマス目そのものは変わりません。

  4. 範囲を選択する

    「選択」を押し、図案上でドラッグして編集したい範囲を囲みます。選択した列数・段数は図案の下に表示されます。Escキーで選択を解除できます。

  5. コピーして貼り付ける

    範囲を選択して「コピー」→「貼り付け」の順に押し、貼り付け先の左上のマスをクリックします。図案の外には貼り付けできません。貼り付け先にある色は上書きされます。

  6. 移動・消去・やり直しをする

    選択後に「移動」を押し、選択範囲の内側からドラッグします。矢印キーでも1目ずつ動かせます。「消去」は選択した範囲を白紙にします。操作を取り消すには右上の「元に戻す」、取り消しを戻すには「やり直す」を使います。

  7. 図案を保存する

    大切な作品は「図案を保存」でJSONファイルに保存してください。図案とパレットが1つのファイルになり、後から「開く」で編集を続けられます。倉庫は含まれません。図案下部の「使用ビーズ一覧」を開くと、使っている品番と粒数を確認できます。

パレットから色を削除するには
色の横の「×」を押します。その色を図案に使っている場合は確認が表示され、削除すると該当するマスが未配置になります。

03 / CATALOGビーズをカタログから選ぶ

自由に作った色に加え、実際のビーズのカタログを参考にできます。

MIYUKIデリカビーズのカタログから、パレットへ色を追加できます。本アプリは株式会社MIYUKIの公式アプリではありません。表示色・質感は目安であり、実物とは異なります。

  1. カタログを開く

    パレットの「＋ カタログから選ぶ」を押します。

  2. 品番・色・加工で絞り込む

    「品番・カラー名」に入力するか、「色系統」「ガラスの種類」で絞り込みます。加工は複数選択でき、選んだ条件をすべて満たすビーズが表示されます。「絞り込みを解除」で条件を戻せます。

  3. 候補を見比べる

    1ページに30品番が表示されます。ページ番号や「前へ」「次へ」で切り替えます。色系統は枠線付き、加工は背景色付きのタグで表示します。「商品写真・説明を確認」から販売サイトを別タブで開けます。

  4. パレットに追加する

    使いたいビーズの「＋ パレットに追加」を押します。追加後はカタログ右上の「×」で閉じ、パレットから色を選んで描いてください。

  5. 図案の色を置き換える

    先にパレットで置き換える色を選び、カタログを開きます。「使い方」を「選択中の色を置き換え」にして候補を選ぶと、図案内の対象色もまとめて置き換わります。

  6. 手持ちのビーズを倉庫に登録する

    量を「ごく少量・3g・7g・20g」から選び（初期値は3g）、「＋ 倉庫に追加」を押します。倉庫への登録とパレットへの追加は別の操作です。

04 / STOCKビーズ倉庫を管理する

手持ちのビーズを登録し、図案づくりに活用できます。

  1. 倉庫を開く

    「＋ 倉庫から選ぶ」を押します。括弧内の数字は、倉庫に登録した品番数です。現在の倉庫はカタログのビーズが対象で、「色を作る」で作成した自由色は登録できません。

  2. 手持ちのビーズを探す

    倉庫内でも品番・カラー名・色系統・加工で絞り込めます。使いたいビーズの「＋ パレットに追加」を押すと図案に使えます。

  3. 量を変更する

    登録済みのビーズのプルダウンで保有量を変更します。これは手動で管理する目安で、図案に使った粒数に応じて自動で減るものではありません。

  4. 倉庫から削除する

    「倉庫から削除」を押すと、倉庫の登録を取り消せます。パレットや描いた図案からは削除されません。

  5. 倉庫を読み込む

    「倉庫を読み込む」で倉庫のJSONファイルを選びます。現在の倉庫リストをファイルの内容で置き換えます。追加・統合ではありません。図案とパレットは変更されません。

  6. 倉庫を保存する

    「倉庫を保存」で、倉庫だけのJSONファイルを書き出します。バックアップや別端末への移動に使ってください。図案を残す操作は「図案を描く」の「図案を保存する」を参照してください。

SAVE / RESTORE自動保存とファイル保存

日々の作業の続きと、作品の保管を使い分けましょう。

方法保存するもの・用途
ブラウザーへの自動保存図案・パレット・倉庫と表示設定。再読み込みや、同じブラウザーで同じサイトを開き直したときに復元します。
図案を保存（JSON）図案とパレット。作品の保管・別端末への移動・後からの編集に使います。
倉庫を保存（JSON）ビーズ倉庫。図案とは別にバックアップできます。
図案の書出し（PDF）図案と使用ビーズの印刷用シート。制作しながら見るための形式です。
自動保存はファイルのバックアップとは異なります。
別の端末・ブラウザーには同期されません。閲覧データを削除すると失われ、プライベートブラウズでは終了後に残らない場合があります。大切な図案・倉庫はJSONファイルにも保存してください。

新しい図案を始めるとき

図案下部の「新規作成」を押します。パレット・サイズ・配置方式・倉庫を引き継いで白紙にします。自動保存される作業内容も新しい図案に置き換わるため、前の作品を残す場合は先に「図案を保存」を使ってください。

自動保存できないと表示されたら

図案と倉庫をそれぞれJSONファイルに保存してください。保存容量やブラウザーの設定によって、自動保存できないことがあります。復元に失敗した場合は「開く」「倉庫を読み込む」で保存済みファイルから戻せます。
